# 📸 TestiMark - Testimonial Watermark & Card Generator (Offline HTML/CSS/JS)

Aplikasi web sederhana & modern untuk menambahkan **Tag Testimoni, Watermark Diagonal, dan Badge Verified** otomatis ke gambar screenshot ulasan pelanggan/penyewa.

---

## ⚡ Keunggulan Aplikasi Ini:
1. **100% Client-Side & Offline:** Tidak butuh server, database, atau koneksi internet. Buka file `index.html` langsung di browser Chrome/Edge/Safari/Firefox!
2. **Auto Image Rendering:** Upload gambar screenshot testimoni → otomatis terpasang badge tag & watermark.
3. **High Resolution Export:** Gambar di-download dengan kualitas tinggi `.PNG` sesuai ukuran asli gambar yang diupload.
4. **Fitur Pengaturan Lengkap:**
   - Nama Toko & Handle (@kedaipremium, DLL)
   - Label Tag Custom (REAL TESTIMONI, VERIFIED TESTI, DLL)
   - Rating Bintang (3-5 Bintang)
   - Teks Watermark Samar Diagonal
   - Pilihan Posisi Badge (Bawah Kanan, Bawah Kiri, Atas Kanan, Atas Kiri)
   - Pilihan Tema Warna (Emerald Trust, Neon Purple, Ocean Cyan, Warm Gold, Dark Glass)
   - Toggle Frame Border Elegant

---

## 🚀 Cara Penggunaan:
1. Masuk ke folder `testi-watermark-tool`.
2. Klik 2x file `index.html` untuk membuka di browser.
3. Drag & Drop gambar screenshot testimoni ke area preview (atau klik "Pilih File Gambar").
4. Sesuaikan nama toko, watermark, dan posisi tag di menu sebelah kiri.
5. Klik **"⚡ Download Gambar Watermark (.PNG)"** — gambar siap diposting di X (Twitter)!
